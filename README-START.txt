GRUNTER – pakiet strony WWW (PHP + MySQL)
========================================

To jest pierwszy kompletny pakiet wdrożeniowy strony i panelu. Nie jest jeszcze opublikowany w Internecie.

WYMAGANIA
- Hosting obsługujący PHP 8.1+ i MySQL
- Baza MySQL utworzona w OVH
- Dostęp FTP/SFTP lub wdrożenie przez Git

INSTALACJA
1. Rozpakuj ZIP na komputerze.
2. Uzupełnij plik config.php danymi bazy OVH (hasło wpisz samodzielnie; nie wysyłaj go nikomu).
3. Wgraj zawartość katalogu do katalogu /www na hostingu.
4. Wejdź na https://grunter.eu/install.php i utwórz konto administratora.
5. Po instalacji usuń install.php z hostingu.
6. Zaloguj się pod adresem https://grunter.eu/admin.php

WAŻNE
- Nie wpisano przykładowych domów jako prawdziwych ofert. Dodaj rzeczywiste inwestycje w panelu.
- Dane firmy w stopce pochodzą z informacji przekazanych w rozmowie; potwierdź je w CEIDG przed publikacją dokumentów.
- Formularz kontaktowy zapisuje zapytania w bazie. Nie wysyła jeszcze e-maili.
- Brak Google Analytics, map Google i pikseli reklamowych.
- Polityka prywatności jest szkicem informacyjnym i wymaga uzupełnienia danych kontaktowych oraz weryfikacji prawnej przed publikacją.
